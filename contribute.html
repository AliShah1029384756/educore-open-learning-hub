Open Contribution

Know a resource worth sharing?

Help another learner find it faster. EduCore welcomes useful, freely accessible educational resources that are relevant, understandable and worth recommending.

Suggest a Resource Open GitHub Issue

How It Works

Three simple steps

1SuggestSend the resource link and a few useful details.
2ReviewThe resource is checked for relevance, accessibility and metadata quality.
3CurateUseful approved resources can be added to the appropriate EduCore category.

Good Submission

What we want

  • Free or genuinely open access for learners
  • Directly useful for a subject, exam, skill or learning level
  • Working, trustworthy and reasonably maintained source
  • Clear title, language, type and learner-level information

Please Avoid

What weakens a submission

  • Spam, unrelated promotion or referral-heavy links
  • Broken, inaccessible or misleading resources
  • Duplicate resources already present in the collection
  • Claims about content that the linked source does not actually provide

One important thing

Submitting a resource does not guarantee publication. EduCore is curated deliberately so the collection stays useful instead of becoming a large unreviewed link dump.
